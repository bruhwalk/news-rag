# news-rag

Новостной RAG-ассистент по экономическим и торговым Telegram-каналам.

## Задача и принцип работы

Пользователь задаёт вопрос и при необходимости временные ограничения.
Ассистент находит публикации, выбирает доказательства и формирует понятный ответ
со ссылками на конкретные посты. Он должен сохранять числа, даты и оговорки,
учитывать исправления и не выдавать устаревшие новости за актуальные.
Если доказательств недостаточно, сообщает об этом или уточняет вопрос.

Планируемый конвейер:

```text
Загрузка и версии постов → временной фильтр → поиск BM25
→ реранкер → сборка контекста → генератор → проверка ссылок → ответ
```

Baseline использует поиск и генератор; MVP добавляет реранкер.
Ответы проверяются офлайн по шести критериям: фактическая корректность,
подтверждённость, актуальность, полнота, обоснованность ответа/отказа и понятность.
Задержка и стоимость измеряются отдельно. Экономия пользовательского времени
остаётся бизнес-гипотезой.

## Текущий статус

Проект находится на этапе проектирования. Подготовлены дизайн системы
и инструменты разработки. Приложение, API, сборщик постов
и оценочный набор ещё не реализованы. Команды запуска сервиса появятся
по мере реализации.

Подробности — в [дизайн-документе](docs/ml_system_design_doc.md).
Дополнительные эксперименты перечислены там отдельно от основного MVP.

## Установка для разработки

Нужны Git и Python 3.12. Все команды выполняются из корня папки `news-rag`.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m pre_commit install
```

## Проверки

```bash
python -m ruff check .
python -m ruff format --check .
python -m pre_commit run --all-files
```

Ruff ищет типовые ошибки, проверяет импорты и форматирование Python-кода.
Pre-commit запускает проверки перед коммитом: Ruff, YAML/TOML, следы конфликтов,
окончания файлов, лишние пробелы и наличие приватных ключей. При ошибке коммит
останавливается. GitHub Actions повторяет проверки после публикации на GitHub.

Для исправления стиля:

```bash
python -m ruff check --fix .
python -m ruff format .
```

Если инструмент изменил файл, проверь результат и заново добавь его в коммит
через `git add`. Успешные проверки кода не подтверждают качество ответов RAG —
его проверка описана отдельно в дизайн-документе.
