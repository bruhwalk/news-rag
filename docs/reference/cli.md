# Параметры запуска news-rag

Команды выполняются из корня проекта. Если индекс уже собран, для ответа достаточно
`news-rag-ask 'Вопрос'`. Штатная конфигурация ищет по Telegram и Trade через
Hybrid (BM25 и E5-small через RRF) и передаёт 20 кандидатов BGE. Затем учитывает свежесть
и собирает контекст для ответа.

## Запрос к RAG

| Параметр `news-rag-ask` | Назначение |
| --- | --- |
| `--as-of ДАТА` | Момент, на который нужен ответ. Публикации и редакции допускаются по времени доступности включительно. От этой же даты считается затухание. Без флага используется текущее время. |
| `--publication-from ДАТА`, `--publication-to ДАТА` | Обе границы периода **публикации** источников. Начало включается, конец исключается. Условия применяются вместе с `as_of`. |
| `--mode bm25`, `dense` или `hybrid` | Выбирает первый этап поиска. BM25 ищет по словам, Dense — по близости векторов, Hybrid объединяет их ранги через RRF. По умолчанию используется Hybrid. |
| `--embedder e5-small` или `e5-base` | Выбирает модель для Dense и Hybrid. Векторы должны быть собраны той же моделью для выбранного снимка. По умолчанию E5-small. BM25 работает по текстовому индексу. |
| `--index ПУТЬ` | Открывает другой SQLite-снимок. Рабочий путь — `data/index/news-mvp-e5.sqlite3`. Для векторного поиска рядом должны лежать векторы этого снимка. |
| `--search-only` | Показывает фрагменты, ссылки и оценки первичного поиска. Использует временные фильтры, пропускает BGE, затухание и генерацию. |
| `--corpus telegram` или `trade` | С `--search-only` ищет только в выбранном источнике данных. При пропуске доступны оба корпуса. |
| `--top N` | С `--search-only` показывает до N фрагментов. По умолчанию 5. |
| `--trace ПУТЬ` | Сохраняет трассу полного запроса в новый локальный JSON-файл. В нём есть кандидаты, их порядок после ранжирования и фактический контекст генератора. Храните трассы с текстами публикаций вне Git. |

Даты передаются в ISO 8601 с часовым поясом. Например, поиск по июньским
публикациям Trade на момент архивного среза выглядит так.

```bash
news-rag-ask 'Что сообщали об изменении российского экспорта?' \
  --as-of 2026-11-09T00:26:01+03:00 \
  --publication-from 2026-06-01T00:00:00+03:00 \
  --publication-to 2026-07-01T00:00:00+03:00 \
  --search-only --corpus trade --top 10
```

Свежесть в полном запросе учитывается автоматически. Прибавка за свежесть
уменьшается вдвое каждые 7 дней от `as_of`. Для распознанных запросов о последних
новостях дополнительно проверяется окно публикаций в 30 дней и свежесть снимка
в пределах 48 часов.

## Сборка индекса и векторов

| Команда и параметр | Назначение |
| --- | --- |
| `build --index ПУТЬ` | Записывает SQLite-снимок по указанному пути. Без флага используется рабочий путь. Для пересборки выберите новый файл. |
| `build --telegram ПУТЬ` | Базовый обработанный JSONL Telegram. По умолчанию `data/processed/telegram/news.jsonl`. |
| `build --trade ПУТЬ` | Базовый обработанный JSONL Trade. По умолчанию `data/processed/trade_news/news.jsonl`. |
| `build --telegram-update ПУТЬ`, `build --trade-update ПУТЬ` | Добавляют файлы обновлений к соответствующей базовой выгрузке при сборке нового снимка. Каждый флаг можно повторять. |
| `build --as-of ДАТА` | Замораживает состав индекса на момент опыта. Более поздние материалы исключаются из сборки и статистики BM25. У `ask --as-of` отсечка применяется к поиску в готовом индексе. |
| `embed --index ПУТЬ` | Читает готовый SQLite-снимок и сохраняет векторы рядом с ним. Без флага используется рабочий путь. |
| `embed --embedder e5-small` или `e5-base` | Выбирает модель для построения векторов. По умолчанию E5-small. Для каждой модели создаётся отдельный комплект. |
| `embed --batch-size N` | Число фрагментов в пакете кодирования. По умолчанию 32. Уменьшите при нехватке памяти. |
| `embed --device УСТРОЙСТВО` | Устройство для кодирования, например `cpu`, `mps` или `cuda`. При пропуске выбирается автоматически. |

```bash
news-rag-index build --index data/index/news-dev.sqlite3 \
  --as-of 2026-11-09T00:26:01+03:00
news-rag-index embed --index data/index/news-dev.sqlite3 --embedder e5-base
```

## Настройки CLI и HTTP API

`NEWS_RAG_INDEX`, `NEWS_RAG_RETRIEVAL` и `NEWS_RAG_EMBEDDER` задают значения
по умолчанию для запросов. Явные флаги `news-rag-ask` имеют приоритет.
`NEWS_RAG_MODEL` выбирает генератор, `NEWS_RAG_TIMEOUT` задаёт бюджет запроса
в секундах, `NEWS_RAG_RERANKER=off` отключает BGE в эксперименте.
